# CLAUDE.md

Guidance for AI sessions working in this repo.

## What this is

A static [Astro 5](https://astro.build) site — a scholar's personal website and
résumé for Rabia Mansoor, with a bold, animated **“Cartography of Narrative”**
design. Deployed as static output on Netlify.

## Commands

Requires **Node 22**. There is **no test suite** — verify changes visually
(chrome-devtools MCP) and by building.

```bash
make dev           # dev server → http://localhost:4321
make build         # build to dist/, then verify the sitemap (fails on regression)
make preview       # serve the production build locally
```

## Architecture

- `src/pages/` — five section routes (`/`, `/journal`, `/lab`, `/classroom`,
  `/about`), the writing index (`/articles/`), and `articles/[...slug]` rendered
  from the `articles` content collection (`src/content/articles/`).
- Shared `BaseLayout` + `BaseHead` handle SEO, GA, favicons, and view
  transitions — page-level files don't repeat that.
- `src/styles/global.css` holds the design tokens and the panel/color system.
- `src/scripts/motion.ts` holds all motion (GSAP + Lenis).

## Conventions that bite if ignored

- Every colored `<section>` needs the base **`panel`** class **plus** a
  `panel--<hue>` modifier. The modifier alone has no padding/clip.
- Per-page signature hue via `<body data-hue="…">`; keep **AA contrast** on
  every field.
- Motion respects `prefers-reduced-motion` and **never hides content without
  JS** — everything is readable in static HTML.
- `/articles/*` reading pages stay calm — no heavy parallax.

## Deploy / SEO

- `PUBLIC_GA_ID` (GA4 id; emits only on prod builds when set) and `SITE`
  (production origin) drive analytics and canonical/sitemap URLs.
- The sitemap is auto-generated by `@astrojs/sitemap`. Keep `public/robots.txt`,
  the `BaseHead` sitemap link, and `site` in `astro.config.mjs` in sync.
